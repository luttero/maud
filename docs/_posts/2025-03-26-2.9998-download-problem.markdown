There was a problem with the installer script for version 2.9998. 
The installers for Windows and LinuX were not generated correctly and contained and old Maud.jar (version 2.9995).
The two installers have been updated with the correct version now.
If you download Maud 2.9998 (Windows or LinuX only) before March 26 (this post), please redownload it with the corrected version.
Sorry for the inconvenient.
If you wish to check if your Maud is the correct 2.9998 version, check at start what version is displaying. That is the correct way to check it.
The "About Maud" box in the MacOS version may still show 2.9997, but what count is the version displayed at start.
