A new MAUD version (2.99993) is available in the releases section.
Added export in the separated plot window (and the phase editing tools menu) to export data for pdfget3(x,n) PDF plotting or post processing.                
Reworked the dynamical correction/extinction models in Maud to have them as a plugin like the rest. So the electron diffraction dynamical 2 beams approximation is now a plugin (extinction models are selected in the phase editing window under advanced models). Added the Sabine extinction models for Neutrons/X-rays. This is the same model used in GSAS (see Sabine, Von Dreele et Jorgensen. Acta Cryst. 1988, A44, 374-379).
Version 2.99992 was never released as it was developed for EPSC4 integration + some bugs corrections. Is basically working but it needs more coding and will be fully functional in the next release hopefully..
Check the video link (Maud youtube video) for a screen recording about the latest features.
