A new MAUD version (2.9997) is available in the releases section.
Fixed a bug with the "Loading Data ..." message never going away,
Improved the Marquard Least Squares algorithm to reduce the number of Cholesky negative diagonal errors and improving the minimization.
Improved the bad pixel mask for importing images (TIFF).
Added sample Y error to the inclined flat reflection images calibration (strangely was left out before).
Added Ga Kalpha(1,2) radiation to the standard X-ray tubes.
