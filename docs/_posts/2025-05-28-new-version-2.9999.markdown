A new MAUD version (2.9999) is available in the releases section.
Fixed another problem with some CIF files with non standard space groups like the C1 or C-1.
Added support for INES instrument at ISIS. Datafiles in GSAS format with instrument parameter file are supported. It is strongly advised to use the Hippo wizard to setup the analysis.
