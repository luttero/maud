A new MAUD version (3.07) is available in the releases section.
Corrected a bug related to the incident intensity correction on TOF neutrons introduced in version 3.05. It waas affecting plots and calculation. Added a Maud preference "plot.phaseIntensityAddBkg" to control if you want to plot the single phase intensities over the background or without.

Download links:

Download from [Google drive][gdrive]
The versions in the directories with "..._x64..." are for Intel/amd cpus, while "..._aarch64..." are for arm type of cpus (Mx processors for Apple Macs).

To download here on github the program and source check on [MAUD download][maud-download]. 
Older versions are available only on github.

To start tutorials are probably the best and can be found at [MAUD tutorials][maud-tutorials].
