<p>There is not much to do to install the program after you have downloaded the proper Maud archive for your system. 

Windows: unzip the Maud.zip archive you downloaded and put the Maud folder you have extracted in your preferred location to run the program. To run Maud, go inside the Maud folder and double click the Maud.bat file to start Maud.

Linux: in the terminal window: "tar –xzf Maud.tar.gz" . Then put/move the extracted folder in your preferred location. Start the Maud program using the Maud.sh inside that folder.

MacOS: double click the Maud_xxx64.dmg.gz to extract the dmg image. Double click the extracted .dmg to mount the image as a disk and drag and drop the Maud.app application inside that disk to your Applications folder or where you want it to be. Eject/unmount the image disk and start the program Maud.app from the folder where you have copied it.</p>
